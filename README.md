# TheDataComrade 🇮🇳💻

A growing collection of SQL interview practice questions and study material — built for anyone prepping for data analyst or data engineer interviews.

Each problem includes a ready-to-run `.sql` file with:
- **Table creation** statements matching the problem's schema
- **Sample data** (usually 20+ rows) so you can actually run and test queries, not just read them
- **A working solution query** at the bottom of the file

## 📂 Repository Structure

```
TheDataComrade/
└── SQL Interview Practice/
    ├── second-highest.sql
    ├── customer-orders.sql
    └── ...
```

More folders and topics (window functions, joins, aggregations, subqueries, etc.) will be added over time.

## 🚀 How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/miSamant/TheDataComrade.git
   ```
2. Open any `.sql` file in your favorite SQL client (PostgreSQL, MySQL, SQLite, etc.)
3. Run the `CREATE TABLE` and `INSERT` statements to set up the practice dataset
4. Try solving the problem yourself before peeking at the solution query included at the bottom of the file
